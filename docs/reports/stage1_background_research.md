**VEGA AS1061 Processor**

The proposed edge-AI detection system is controlled by the **VEGA AS1061**, a 64-bit RISC-V processor IP developed by the **Centre for Development of Advanced Computing (C-DAC), Trivandrum, India**. The processor follows the **RV64G RISC-V instruction set architecture**, which includes integer instructions, multiplication and division extensions, atomic operations, and floating-point support. The adoption of the open-standard RISC-V ISA is particularly advantageous for research and embedded system development because it avoids vendor lock-in and allows the processor to be integrated and customized within FPGA-based systems.

The VEGA AS1061 processor is designed to support application-class workloads while remaining suitable for embedded platforms. Internally, it uses a **six-stage in-order pipeline architecture** combined with **advanced branch prediction mechanisms**, including a Branch Target Buffer (BTB), Branch History Table (BHT), and Return Address Stack (RAS). These mechanisms improve execution efficiency by reducing pipeline stalls caused by control-flow instructions. The processor also supports both **machine mode and supervisor mode privilege levels**, allowing it to run operating systems such as Linux as well as lightweight embedded environments.

To improve execution performance, the AS1061 includes configurable **Level-1 instruction and data caches**, typically configured as **8 KiB I-cache and 8 KiB D-cache**. The processor also integrates a **high-performance IEEE-754 compliant floating-point unit**, enabling efficient execution of floating-point operations that commonly appear in signal processing and machine-learning workloads. A **Platform Level Interrupt Controller (PLIC)** with support for multiple interrupt sources and vectored interrupt handling allows the processor to efficiently manage system events and peripheral interactions.

For system integration, the processor provides **AXI4 or AHB standard bus interfaces**, making it straightforward to connect with memory controllers, peripherals, and custom hardware accelerators implemented within the FPGA fabric. This capability is critical for heterogeneous computing systems where specialized hardware modules are used to accelerate computationally intensive tasks. The processor also includes **JTAG-based debugging support**, enabling developers to perform hardware and software debugging through tools such as OpenOCD and GDB.

Within the proposed architecture, the VEGA AS1061 processor primarily serves as the **system controller and orchestration unit**. Rather than executing the entire object detection workload directly, the processor manages system initialization, memory operations, and data transfer between system memory and the custom accelerator. It also handles tasks such as preprocessing, post processing, scheduling of inference operations, and interaction with external interfaces. The computationally intensive parts of the detection pipeline, particularly neural network inference and associated matrix operations, are offloaded to a dedicated hardware accelerator implemented in the FPGA fabric. This heterogeneous architecture allows the system to combine the flexibility of a programmable processor with the high performance of specialized hardware.

**Genesys-2 FPGA Platform**

The hardware platform used to develop and evaluate the proposed system is the **Digilent Genesys-2 FPGA development board**, which is built around the **Xilinx Kintex-7 XC7K325T FPGA**. This platform provides a powerful and flexible environment for implementing complex digital systems that combine processors, memory subsystems, and custom hardware accelerators.

The Kintex-7 FPGA available on the Genesys-2 board offers a large amount of programmable logic resources, including approximately **50,950 logic slices**, **16 Mbits of on-chip Block RAM (BRAM)**, and **840 DSP slices**. These DSP slices are particularly important for machine-learning and signal-processing workloads because they provide hardware-optimized multiply-accumulate operations that can significantly accelerate arithmetic computations. The combination of configurable logic, memory resources, and DSP blocks makes the FPGA well suited for implementing custom accelerators targeting compute-intensive tasks such as convolution, matrix multiplication, and feature extraction.

In addition to on-chip FPGA resources, the Genesys-2 board includes **1 GB of DDR3 external memory**, which is essential for storing input data, intermediate feature maps, and model parameters associated with the object detection pipeline. Since the on-chip BRAM capacity of the FPGA is limited compared to the size of modern machine-learning models, the external DDR3 memory provides the large storage space required for practical deployment of AI workloads.

The board also provides a wide range of connectivity options that support system development and debugging. These include **Gigabit Ethernet**, **USB-UART communication**, **HDMI and VGA display interfaces**, and **Pmod expansion connectors**. These peripherals allow the platform to interact with cameras, external processors, and user interfaces while also enabling efficient debugging and monitoring during system development.

The reconfigurable nature of the FPGA is particularly important for this project. The Genesys-2 platform allows both the **VEGA AS1061 processor IP and the custom hardware accelerator** to be instantiated within the same FPGA fabric. This integration enables a **heterogeneous computing architecture**, where the processor manages system control and communication while the accelerator performs high-throughput computation. Such architectures are widely used in modern edge-AI systems because they provide a balance between flexibility and computational efficiency.

Another important aspect of the Genesys-2 platform is its resource capacity. The FPGA must accommodate the processor subsystem, memory interfaces, communication buses, and custom accelerator simultaneously. While the processor and associated infrastructure consume a portion of the available logic and memory resources, the remaining resources can be utilized to implement the accelerator. Careful architectural design is therefore required to ensure that the accelerator efficiently utilizes the available **DSP slices, BRAM blocks, and logic resources** while maintaining acceptable timing performance.

Overall, the Genesys-2 FPGA platform provides a suitable foundation for implementing the proposed edge-AI system. Its combination of programmable logic resources, external memory capacity, and rich peripheral interfaces enables the integration of the VEGA processor with custom accelerator hardware, allowing the system to achieve significantly higher performance compared to a processor-only implementation.
